# Product page
este es un proyecto demo de una pagina de producto web responsive, para este ejemplo vamos hacer una pagina para vender un asador por lo que la pagina va a tener una estetica que se ajuste a equipos de campoing y parrilladas

# features layout
- navbar con logo de la pagina (usaremos "abx camping" como marca para este demo) algunos links que no lleven a ningun lado como contacto, about, alugnos menos desplegables como equipo de campong que al hacer hover muestre una lista de cosas para camping como sleeping bags, casa de campaña, mochilas, etc; uno de parrilladas que muestre asadores, utencilios de cocina, carbon e iniciadores de fuego, mandiles y guantes, etc.
- body de la pagina
- footer de la pagina
- agregar al carrito va a mostrar en el lateral derecho unpanel con lo que hay en el carrito y un boton para ir al carritoy uno de close o clickear en el body tambien cierra este panel

# body
- titulo de producto
- imagen del producto
- carousel de imagenes
- variantes (por ejemplo tamaño mediano y grande)
- informacion del producto
- precio
- metodos de pago
- boton add to cart
- descripcino del producto
- productos recomendados (para este ejemplounaspizas y una funda)
- seccion de preguntas y respuestas
- seccion de reviews

# estetica
buscamos que la pagina tenga una estetica que  haga alusion a actividades al aire libre como el verde del campo, esto para acentuar cosas como el navbar o links estos ultimos pueden ser azules glaciar o algun tono natural, el fondo de la pagina blanco o un tono muy claro para no distraer tanto la vista del cliente
